# Phase 3: AI-Powered Todo Chatbot

## Overview

Transform the todo application into an AI-powered chatbot for natural language task management.

## Status

**Phase Status**: Not Started

## Technology Stack

- **UI**: OpenAI ChatKit
- **AI Framework**: OpenAI Agents SDK
- **MCP Server**: Official MCP SDK (Python)
- **Backend**: FastAPI (from Phase 2)
- **Database**: Neon PostgreSQL

## Features

Manage tasks via natural language:
- "Add task: buy groceries"
- "Show my tasks"
- "Mark task 1 as done"
- "Delete task 3"
- "Update task 1 title to 'Buy organic groceries'"
